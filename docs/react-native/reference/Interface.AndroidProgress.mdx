## Properties

### current?

> `optional` **current?**: `number`

Defined in: [packages/react-native/src/types/NotificationAndroid.ts:857](https://github.com/New-Elysium/notifee/blob/main/packages/react-native/src/types/NotificationAndroid.ts#L857)

The current progress value.

E.g. setting to `4` with a `max` value of `10` would set a fixed progress bar on the notification at 40% complete.

***

### indeterminate?

> `optional` **indeterminate?**: `boolean`

Defined in: [packages/react-native/src/types/NotificationAndroid.ts:865](https://github.com/New-Elysium/notifee/blob/main/packages/react-native/src/types/NotificationAndroid.ts#L865)

If `true`, overrides the `max` and `current` values and displays an unknown progress style. Useful when you have no
knowledge of a tasks completion state.

Defaults to `false`.

***

### max?

> `optional` **max?**: `number`

Defined in: [packages/react-native/src/types/NotificationAndroid.ts:850](https://github.com/New-Elysium/notifee/blob/main/packages/react-native/src/types/NotificationAndroid.ts#L850)

The maximum progress number. E.g `10`.

Must be greater than the `current` value.

***

### points?

> `optional` **points?**: [`AndroidProgressPoint`](react-native/reference/Interface.AndroidProgressPoint)\[]

Defined in: [packages/react-native/src/types/NotificationAndroid.ts:880](https://github.com/New-Elysium/notifee/blob/main/packages/react-native/src/types/NotificationAndroid.ts#L880)

Point markers for Android 16+ progress-centric notifications.

Positions use the same unit as `segments[].length`.

***

### segments?

> `optional` **segments?**: [`AndroidProgressSegment`](react-native/reference/Interface.AndroidProgressSegment)\[]

Defined in: [packages/react-native/src/types/NotificationAndroid.ts:873](https://github.com/New-Elysium/notifee/blob/main/packages/react-native/src/types/NotificationAndroid.ts#L873)

Segment definitions for Android 16+ progress-centric notifications.

When provided, `segments` become the source of truth for the total progress length and `max`
must not be set.

***

Defaults to `true` when omitted by the native Android 16+ ProgressStyle builder.
