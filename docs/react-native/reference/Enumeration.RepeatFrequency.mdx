# Enumeration: RepeatFrequency

Defined in: [packages/react-native/src/types/Trigger.ts:102](https://github.com/New-Elysium/notifee/blob/main/packages/react-native/src/types/Trigger.ts#L102)

An interface representing the different frequencies which can be used with `TimestampTrigger.repeatFrequency`.
Supported timestamp repeat frequencies are hourly, daily, weekly, and monthly.
Yearly recurrence is not supported.

View the [Triggers](/react-native/triggers) documentation to learn more.

## Enumeration Members

> **DAILY**: `1`

Defined in: [packages/react-native/src/types/Trigger.ts:114](https://github.com/New-Elysium/notifee/blob/main/packages/react-native/src/types/Trigger.ts#L114)

### MONTHLY

> **MONTHLY**: `3`

Defined in: [packages/react-native/src/types/Trigger.ts:127](https://github.com/New-Elysium/notifee/blob/main/packages/react-native/src/types/Trigger.ts#L127)

Repeat every calendar month from the timestamp.

Use `TimestampTrigger.repeatInterval` for intervals such as every 3 months.
Monthly repeats use native calendar semantics; dates that do not exist in a
target month are adjusted by the platform calendar. Requires AlarmManager
(the default on Android); not supported with `alarmManager: false`.

***
