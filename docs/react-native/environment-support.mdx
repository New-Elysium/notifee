## Support Table

The below table contains the current tested and supported environments in which Notifee is compatible with:

| Environment                                           | Supported             | Notes                                               |
| ----------------------------------------------------- | --------------------- | --------------------------------------------------- |
| React Native                                          | >= 0.83               | New Architecture required.                          |
| Android APIs                                          | Android 9.0+ (API 28) | `minSdk = 28`, `compileSdk = 36`, `targetSdk = 35`. |
| iOS Version                                           | 15.1+                 | Matches the `RNNotifee.podspec` platform target.    |
| [Hermes Support](https://reactnative.dev/docs/hermes) | Yes                   | Default on modern React Native.                     |
| Packagers                                             | Metro                 | Untested on non-standard packagers.                 |

## Additional Requirements

- For iOS development, Xcode 16.2+ is required
